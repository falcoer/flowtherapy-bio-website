| Famille | Source conservée | Sortie CI |
|---|---|---|
| Bangers | `bangers/Bangers-Regular.ttf` | `bangers-regular.woff2` |
| Inter | `inter/Inter-Variable.ttf` | `inter-variable.woff2` |
